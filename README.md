# Sistema de Avaliação de Competências

Projeto Integrador da disciplina de Desenvolvimento Front-end para Web.

Sistema web demonstrativo para avaliação de competências técnicas e comportamentais de colaboradores de escritórios de advocacia.

O projeto permitirá apresentar questionários, visualizar resultados fictícios e explorar oportunidades de desenvolvimento profissional.

Desenvolvido inicialmente com HTML, CSS e JavaScript.
